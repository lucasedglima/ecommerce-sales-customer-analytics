# E-commerce Sales & Customer Analytics

Projeto de análise de dados de um e-commerce brasileiro desenvolvido para aplicar SQL, PostgreSQL, Power Query, Power BI e DAX na resolução de problemas de negócio.

## Objetivo

Construir uma solução de análise de vendas e comportamento de clientes, partindo de dados brutos até a criação de um dashboard interativo.

Durante o projeto serão analisados indicadores como:

* Faturamento;
* Quantidade de pedidos;
* Ticket médio;
* Desempenho de produtos e categorias;
* Distribuição geográfica das vendas;
* Formas de pagamento;
* Prazos de entrega;
* Avaliações dos clientes;
* Recorrência de compra.

## Tecnologias

* PostgreSQL
* SQL
* Power Query
* Power BI
* DAX
* Git e GitHub

## Dataset

Será utilizado o Brazilian E-Commerce Public Dataset by Olist, disponibilizado no Kaggle. O conjunto possui aproximadamente 100 mil pedidos realizados entre 2016 e 2018, além de informações sobre clientes, produtos, pagamentos, vendedores, entregas e avaliações.

## Estrutura do projeto

* `data/`: dados brutos e processados utilizados localmente;
* `database/`: criação, carregamento e validação do banco;
* `sql/`: consultas SQL organizadas por assunto;
* `power-bi/`: arquivos relacionados ao dashboard;
* `docs/`: documentação, diagramas e imagens.
